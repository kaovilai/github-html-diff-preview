Rendered HTML Diff for GitHub

Everything runs in your browser. Files are fetched directly from GitHub; nothing is sent anywhere else.

How files are fetched

Browser login reuses the GitHub session already in this browser, so private repositories work without storing anything. File content and images/fonts/CSS use this. Pull request diffs need GitHub's API, which a browser login cannot access, so private-repository diffs need a token below.

Personal access token (optional)

Stored only in this browser (chrome.storage.local) and sent only to api.github.com. Use a fine-grained token limited to the repositories you need, with read-only Contents and Pull requests permissions.
