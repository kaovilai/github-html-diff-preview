GitHub HTML Diff Preview

Everything runs in your browser. Files are read from GitHub with the sign-in already in this browser; nothing is sent anywhere else. There is nothing to configure and no token to store.

How it reads files

The extension only reads: it requests a file's Raw address on github.com, using your existing GitHub sign-in, so private repositories you can open work and public ones work signed out. It never uploads anything and never uses the GitHub API. For a pull request, the two commits being compared are read from the GitHub page you are on.
