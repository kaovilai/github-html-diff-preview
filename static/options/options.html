GitHub HTML Diff Preview

Everything runs in your browser. Files are fetched directly from GitHub; nothing is sent anywhere else.

How files are fetched

Browser login reuses the GitHub session already in this browser, so private repositories work without storing anything. File content and images/fonts/CSS use this. Pull request diffs normally need nothing more: the compared commits are read from the GitHub page itself. A token below is only a fallback, for when the page does not expose them.

Personal access token (optional fallback)

Stored only in this browser (chrome.storage.local) and sent only to api.github.com. Use a fine-grained token limited to the repositories you need, with read-only Contents and Pull requests permissions.
